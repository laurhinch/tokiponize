tokiponize

Turn any name into phonotactically valid toki pona. Type a name and get the best fit plus scored alternatives.

o sitelen e nimi!

ilo li pona ala pona? · how good is it?

Tested on ~4,900 real tokiponizations from Wikidata's toki pona labels, using only names the tool was never tuned on:

engine exact match in top 4 in top 8
standard 41% 51% 52%
experimental 41% 54% 57%

Most misses are names based on what a place calls itself, which spelling alone doesn't show. Details and data live in eval/.

API

Free, no key, CORS open, 60 requests a minute. Any tool that can fetch a URL can use it. 

curl "/tokiponize?name=Marseille"
{
  "name": "Marseille",
  "best": "Masi",
  "candidates": [{ "name": "Masi", "score": -1.75 }, ...]
}

Options: &limit=8, &experimental=1. There is also /check?name=Koti to test whether a name is already valid toki pona. In JavaScript you can skip the API and npm install tokiponize instead.
